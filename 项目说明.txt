# 任务：开发一个"生成时安全"的代码生成 Skill

## 一、项目背景

当前在 vibe-coding（AI 自由生成代码）场景中，大模型经常忽略安全性，生成包含漏洞（如 SQL 注入、命令注入、硬编码密钥等）的代码。我需要你开发一个 **Skill / 插件**，它不是"先生成后检查"，而是在 **代码生成过程中就引导模型写出安全代码**。

## 二、核心目标

开发一个 Python 编写的安全生成 Skill，具备以下能力：

1. **安全上下文构建**：根据用户的任务描述、语言、框架，动态构建包含安全编码规则的 System Prompt。
2. **实时安全校验**：对模型生成的代码进行毫秒级校验（基于 AST + 正则），检测危险模式。
3. **自动修正循环**：校验不通过时，将违规信息反馈给模型重新生成，最多重试 3 次。
4. **日志记录**：完整记录每次生成的输入、输出、校验结果、重试次数，便于后续迭代。
5. **规则可迭代**：安全规则存储在 YAML/JSON 文件中，可随时增删改，无需改动核心代码。

## 三、技术约束

- 使用 Python(版本询问我)
- 不依赖重型外部工具（不用 Semgrep 等），但可以调用agent额外的算力（如 OpenAI / Claude）进行代码生成
- 规则引擎基于 Python `ast` 模块 + 正则表达式
- 安全规则、禁用模式、安全模板分别存储为 YAML 或 JSON 文件
- 提供清晰的日志格式（JSON），供后续分析使用

## 四、功能要求（详细）

### 1. 安全上下文构建器
- 输入：`task\_description`、`language`、`framework`、`context`
- 输出：构建好的 `system\_prompt` 和 `user\_prompt`
- 规则来源：从 YAML 文件加载，按语言/框架筛选
- Prompt 必须包含：
  - 角色设定（安全编码专家）
  - 通用安全规则清单
  - 特定语言/框架的规则
  - 禁用模式黑名单
  - 安全代码模板（few-shot 示例）
  - 输出格式要求（自检清单）

### 2. 实时安全校验器
- 输入：代码字符串、语言类型
- 输出：校验结果（通过/不通过）、违规列表（规则ID、代码行、说明）
- 检测项至少包括（不限于）：
  - 危险函数调用（`eval`、`exec`、`os.system`、`subprocess.call(shell=True)`、`pickle.loads`）
  - SQL 字符串拼接
  - 硬编码密钥/密码
  - 明文 HTTP 链接
  - 不安全的随机数生成

### 3. 自动修正循环
- 当校验不通过时，将违规信息作为错误反馈给 LLM
- 要求 LLM 重新生成代码，最多 3 次
- 第 3 次仍失败时，输出原始代码 + 完整的漏洞报告，标记为"需人工修复"
（这个技术也可以不依赖这个原则，只是我目前的构想，你有什么新的高效的想法么）

### 4. 日志记录器
- 记录字段：时间戳、任务描述、语言、框架、上下文、首次生成代码、校验结果、重试次数、最终代码、用户是否手动修改、修改 diff
- 输出为 JSON Lines 格式

### 5. 规则文件结构
- `rules/general.yaml`：通用安全规则（跨语言）
- `rules/python.yaml`：Python 特定规则
- `blacklist/python.yaml`：Python 危险模式黑名单
- `templates/python/`：安全代码模板（按功能分类，如 auth.py、db.py、file_upload.py）
